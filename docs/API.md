# API examples

Create a full world:

```bash
curl -sS http://127.0.0.1:4317/api/worlds \
  -H 'content-type: application/json' \
  -d '{"brief":"A monastery records dreams that have not happened yet."}'
```

Create only selected formats:

```bash
curl -sS http://127.0.0.1:4317/api/worlds \
  -H 'content-type: application/json' \
  -d '{"brief":"A solar-punk heist in a vertical orchard.","artifactTypes":["game_world","storyboard","visual_novel"]}'
```

Start and advance a session:

```bash
curl -sS -X POST http://127.0.0.1:4317/api/worlds/WORLD_ID/sessions \
  -H 'content-type: application/json' -d '{}'

curl -sS -X POST http://127.0.0.1:4317/api/worlds/WORLD_ID/sessions/SESSION_ID/choose \
  -H 'content-type: application/json' -d '{"choiceId":"choice_trust"}'
```

Bind media generated by another agent or service:

```bash
curl -sS -X POST http://127.0.0.1:4317/api/worlds/WORLD_ID/assets \
  -H 'content-type: application/json' \
  -d '{"briefId":"storyboard_hero_image","kind":"image","title":"Key art","uri":"https://cdn.example/key-art.webp","alt":"Rowan and Mara in the Rain Market"}'
```

Agents should begin with `GET /api/capabilities` instead of hard-coding the
format list. Errors use JSON `{ error, message, issues? }` with HTTP 400, 404,
or 500 status codes.
