# Contributing

Thanks for helping agents make better worlds.

1. Open an issue for contract changes. Existing world JSON must remain readable.
2. Keep model/provider code behind an adapter boundary.
3. Add or update a focused test for behavioral changes.
4. Run `npm run check` before opening a pull request.
5. Keep creative prompts vendor-neutral and the demo adapter deterministic.

Pull requests should state the user problem, the behavior changed, and the
checks run. Please do not commit generated worlds, API keys, logs, or model
outputs containing private source material.
